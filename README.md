# File Management System

A simple Python-based command-line application for managing files.

## Features

* Create a new file
* Read file contents
* Rename a file
* Append content to a file
* Overwrite file content
* Delete a file

## Technologies Used

* Python
* pathlib
* File Handling

## How to Run

```bash
python main.py
```

## Menu

```text
1. Create a file
2. Read a file
3. Update a file
4. Delete a file
```

## Purpose

This project was created to practice Python file handling, `pathlib`, functions, user input, and exception handling.
